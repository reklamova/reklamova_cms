- `app/core/**`,

- `app/themes/**`,
- `app/modules/custom/**`,
- `public/uploads/**`,
- backupów i logów,

- konfiguracji stagingowych.

Patch MERO pozostaje osobnym wdrożeniem. Aktualizacja core nie instaluje i nie
nadpisuje `app/modules/custom/mero`.

## Aktualizacja

1. Zaloguj się jako Reklamova Admin.
2. Otwórz `Aktualizacje CMS`.
3. Uruchom sprawdzenie wymagań i dry run.
4. Potwierdź utworzenie backupu core i bazy.
5. Uruchom aktualizację.
6. Po zakończeniu sprawdź front, panel, formularze i aktywne moduły.

Aktualizacja może zmienić tylko pliki core objęte manifestem. Konfiguracja,
motyw, custom moduły i uploady pozostają chronione.

## Rollback

Jeśli health check po aktualizacji nie przejdzie, updater powinien automatycznie:

1. zatrzymać aktualizację,
2. przywrócić poprzedni core z backupu,
3. przywrócić bazę, jeśli wykonano migracje,
4. wyłączyć maintenance mode,
5. zapisać błąd w logu aktualizacji.

Przed ręcznym rollbackiem należy zachować aktualne logi i manifest backupu.
Ręczne przywrócenie wykonuje wyłącznie Reklamova Admin.
