## Decyzja

działającego clean stagingu oraz przeglądarkowego testu trwałości zgody. Nie
wykonano merge do `main`, nie zbudowano stable i nie zmieniono produkcji.

Po naprawie hasła MySQL trzeba:

1. uruchomić clean staging,
2. zaktualizować go do RC2,
3. wykonać pełny i ponowny ciąg migracji,
4. przejść checklistę Privacy Center w przeglądarce na trzech stagingach,
5. uzupełnić ten raport i dopiero wtedy rozważyć `GOTOWE DO MERGE`.
