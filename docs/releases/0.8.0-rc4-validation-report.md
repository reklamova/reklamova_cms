## Zamknięty blocker

Pierwszy test zapisu powielonego produktu ujawnił błąd `json_encode()` dla
starszych parametrów zawierających nieprawidłowe sekwencje UTF-8.

Przed finalizacją RC4:

- dodano bezpieczną serializację z `JSON_INVALID_UTF8_SUBSTITUTE`,
- przebudowano i ponownie podpisano paczkę,
- zastąpiono wcześniejszy artefakt RC4,
- powtórzono zapis na realnych danych PowerTech,
- usunięto wszystkie produkty testowe,
- potwierdzono powrót liczby produktów do 104,
- powtórzono testy regresji i responsywności.

Finalny SHA-256 RC4 podany w tym raporcie obejmuje poprawkę.
