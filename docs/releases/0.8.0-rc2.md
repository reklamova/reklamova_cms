# Reklamova CMS Core 0.8.0-rc2

Kanał: `rc`

Package ID: `pkg_core_0_8_0_rc2`

## Cel

RC2 zawiera poprawki znalezione po zbudowaniu RC1:

- globalne hooki Privacy Center w pełnoekranowych rendererach,
- deduplikację elementów i assetów Privacy Center,
- canonical oraz aliasy dokumentów prywatności,
- usunięcie starego popupu MERO przez osobny patch custom,
- snapshot zgody formularza MERO,
- funkcję `Powiel produkt`,
- zaufany klucz publiczny Ed25519 dla kanału `rc`.

## Zakres core

Paczka może zawierać wyłącznie ścieżki core wymienione w
`tools/build-update-package.php` i `reklamova.json`.

Paczka nie może zawierać:

- `app/config` poza `placements.example.php`,
- `app/themes`,
- `app/modules/custom`,
- `public/uploads`,
- `app/storage/backups`,
- `app/storage/logs`.

Zmiany `app/modules/custom/mero` pozostają oddzielnym patchem MERO i nie są
częścią core RC2.

## Stan

RC2 jest kandydatem do kontrolowanych testów stagingowych. Nie wolno publikować
go na kanale `stable` ani scalać do `main` przed raportem walidacji.
