## MERO custom patch

Wynik: **WYCOFANY**

Przed wdrożeniem utworzono:

- backup modułu: `mero_custom_patch_0_8_0_20260730_124128`,
- backup core i bazy: `bkp_20260730_124129`.

Wgrano wyłącznie cztery zatwierdzone pliki modułu MERO. Lint PHP przeszedł,
a migracja modułu była idempotentna. Test przeglądarkowy wykazał jednak
rzeczywistą regresję: po patchu `/kontakt` zwracał HTTP 200, ale nie renderował
formularza kontaktowego. Zgodnie z kryteriami zatrzymania rollout został
przerwany.

Rollback wykonano pod maintenance mode:

1. przywrócono cały katalog `app/modules/custom/mero`,
2. przywrócono bazę z `bkp_20260730_124129`,
3. wyczyszczono cache,
4. wyłączono maintenance mode,
5. wykonano ponowny lint i smoke test.

Po rollbacku hash modułu MERO wrócił dokładnie do wartości sprzed patcha:
`5a3c8f3ec015534bbdf2cc54c132f0e00ed53cf33ea2eb27d639a2c2c6392b2d`.
Core pozostał na wersji `0.8.0`.

Końcowy test po rollbacku potwierdził:

- logowanie i panel: poprawne,
- Poradnik: 6 aktywnych linków,
- Zapytania: ekran działa,
- Kalkulator: wynik obliczany,
- formularz kontaktowy: obecny, walidacja i snapshot zgody działają,
- mechanizm zgód: jedna instancja, decyzja trwała po odświeżeniu,
- skrypty analityczne i marketingowe: niezaładowane przed decyzją,
- widoki 390 i 768 px: bez globalnego poziomego przewijania,
- błędy runtime i HTTP 500: brak.

Po wycofaniu patcha MERO używa dotychczasowej integracji zgód z motywu. Nowy
patch wymaga ponownego przygotowania na stagingu tak, aby włączyć core Privacy
Center bez przejmowania routingu stron publicznych i bez utraty formularza.

## Porządkowanie

- tymczasowe konta rollout zostały usunięte,
- pomocnicze skrypty wdrożeniowe zostały usunięte z obu hostingów,
- dane logowania testowego zostały usunięte lokalnie,
- 41 plików PHP core i modułu MERO przeszło końcowy lint na produkcji,
- logi nie zawierają nowych błędów krytycznych,
- nie aktualizowano żadnych innych instalacji.

## Następny krok

PowerTech i MERO core pozostają w obserwacji. Rollout pozostałych instalacji
jest wstrzymany. Patch MERO należy poprawić i ponownie zwalidować na stagingu,
ze szczególnym testem routingu `/kontakt`, formularza, Kalkulatora oraz jednej
instancji Privacy Center.
