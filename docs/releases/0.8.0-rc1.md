# Reklamova CMS Core 0.8.0-rc1

Data przygotowania: 2026-07-28

Kanał aktualizacji: `rc`

## Co zmienia 0.8.0

- porządkuje architekturę informacji panelu klienta,
- rozdziela menu klienta od sekcji technicznej Reklamova,
- dodaje jawne role, uprawnienia i widoczność modułów,
- uzależnia dashboard i menu od aktywnych funkcji,
- upraszcza nazwy ekranów i treści,
- dodaje placementy dla modułów zależnych od motywu,
- utwardza migrację metadanych modułów,
- przygotowuje ścisły zakres bezpiecznej aktualizacji core.

`docs/releases/mero-custom-patch-0.8.0.md`.

## Staging

Plan środowisk i instrukcja izolowanego klonowania:

- `docs/testing/staging-environments-0.8.0-rc1.md`
- `docs/testing/safe-staging-clone-0.8.0-rc1.md`

1. Wdróż core RC do odizolowanej instalacji z kanałem `rc`.
2. Uruchom pełny PHP lint.
3. Uruchom pełny ciąg migracji na pustej bazie.
4. Powtórz migracje na kopii bazy MERO.
5. Powtórz migracje na kopii bazy PowerTech.
6. Zaloguj się jako `client_admin` i `reklamova_admin`.
7. Sprawdź menu, dashboard, Podstrony, Media, formularze i Privacy Center.
8. Sprawdź `/admin/updates` bez `manage_updates`.
9. Sprawdź `/admin/system` z `manage_updates`.
10. Wdróż osobny patch MERO wyłącznie na MERO staging.
11. Wykonaj checklistę `docs/testing/mero-admin-ux-0.8.0-rc1.md`.

## Rollback

1. Włącz maintenance mode.
2. Przywróć backup core utworzony przed wdrożeniem.
3. Przywróć bazę, jeśli wykonano migracje i test wykazał regresję.
4. Wyczyść cache.
5. Wyłącz maintenance mode.
6. Sprawdź stronę publiczną, logowanie i główne ekrany panelu.

Patch MERO cofa się niezależnie zgodnie z jego własną instrukcją.

## Ryzyka

- konfiguracje aktywnych modułów na MERO i PowerTech mogą ujawnić różnice,
  których nie odtwarza test syntetyczny,
- pełny ciąg starszych migracji nie został jeszcze uruchomiony na pustej bazie,
- custom patch MERO wymaga osobnego backupu i wdrożenia,
- RC nie może zostać opublikowany na kanale `stable`.

## Decyzja

NIEGOTOWE DO MERGE DO `main`.

Kodowe testy RC są czyste, ale przed merge muszą przejść trzy testy baz danych
oraz ręczny staging MERO. Nie zbudowano paczki produkcyjnej i nie opublikowano
aktualizacji na update serverze.
